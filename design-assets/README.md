# Original artwork

The full-resolution files Kate supplied. **Nothing in this folder is published
to the website** — it's kept here so the originals are never lost, and so the
19MB headshot isn't shipped to every visitor's phone.

| File | What the site uses it for |
| --- | --- |
| `kate-logo-branch.png` | Source for `public/images/logo.png` and `logo-light.png` (header + footer), and the share card |
| `kate-logo.png` | Source for the circular "ki" mark used as the browser/app icon |
| `headshot-kate.png` | Source for `public/images/kate-headshot.jpg` on the About page |

Use these originals for anything print- or social-sized. If you replace a file
in `public/images/`, drop the new original in here too.
